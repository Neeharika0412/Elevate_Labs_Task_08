# Elevate_Labs_Task_08

Task 8 – Simple Sales Dashboard
Objective

This task was part of the Data Analyst Internship, where I created a basic interactive sales dashboard to analyze sales performance by product, region, and time.

Tools Used

Tableau – for dashboard creation

Excel/CSV (Superstore_Sales.csv) – dataset provided


 Dataset

The dataset used was Superstore_Sales.csv, which contains:

Order Date

Region

Category

Sales

Profit

Dashboard Features

Line Chart: Sales trend over months

Bar Chart: Sales by region

Donut Chart: Sales by product category

Filter/Slicer: Added for Region (to make dashboard interactive)

Insights Section: Highlighted 3–4 business insights

 Key Insights

East region recorded the highest sales (~1900), while Central had the lowest (~1590).

Furniture was the top-selling category (~3280).

Sales peaked in March 2020 (~1070) but fell significantly in April 2020 (~550).

Technology category contributed better profit margins compared to Furniture.
